# LineGuard landing page

Static website for Cloudflare Pages. There is no build step and no framework dependency.

## Put it on your existing site

1. Download and unzip this package.
2. Open your existing `lineguard_landing` repository on GitHub.
3. Choose **Add file → Upload files** and drag in `index.html`, `styles.css`, and the entire `assets` folder. Keep the `assets` folder name and structure. You do not need to upload this README.
4. Commit to `main`. Your connected Cloudflare Pages project should redeploy automatically.
5. Open the Pages deployment URL to verify the page before connecting `lineguardapp.com` in **Custom domains**.

The App Store callout deliberately has no outbound link until an App Store listing is available. The contact links address `hello@lineguardapp.com`.

No privacy policy or terms links are included because those documents were not supplied. Add the actual policies and link them in the footer before using the site as the support or privacy destination in an app listing.
