# LineGuard website

Upload all contents of this ZIP to the root of your existing GitHub repository, preserving the privacy/ and support/ folders. Do not upload the ZIP itself. Cloudflare deploys after committing to main.

There is no build step. The iOS App Store buttons link to the live LineGuard listing. The landing page contact address is hello@lineguardapp.com.

The footer links to English and Spanish privacy policies at https://lineguardapp.com/privacy/ and https://lineguardapp.com/privacy/es/. The privacy and support pages are copies of the previously published LineGuard pages, with links and images adjusted for this domain. The policy pages list info@gatherwith.app for privacy and support inquiries.
